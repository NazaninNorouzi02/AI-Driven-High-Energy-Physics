# Assignment 2 — Signal Processing & Noise Estimation in Detection Systems

## Overview

### Exercise 01: Signal Processing in a PET System
- Estimate the positron emission flux from a PET radionuclide and analyze the resulting 511 keV gamma-ray flux entering a scintillation detector. 
- Evaluate different scintillation materials (light yield, decay time) and calculate total photon production per gamma event. 
- Model the detection chain including light collection efficiency, photocathode quantum efficiency, and PMT gain to determine electron yield and voltage pulse amplitude. 
- Determine the fractional energy resolution using Poisson statistics. 
- Discuss noise contributions such as statistical fluctuations, electronic noise, and thermal noise, identifying the dominant source.

### Exercise 02: CCD Noise Estimation with Finite Background Sampling
- Derive the signal-to-noise ratio (SNR) for an ideal CCD system with background estimated over multiple pixels. 
- Modify the SNR expression for finite background sampling. 
- Incorporate real-world detector effects such as dark current and read noise, demonstrating how read noise decreases with exposure time while dark current contribution does not.

### Exercise 03: Optical Properties and Magnification of Telescopes Observing the Moon
- Compare telescope configurations with different objective diameters and focal lengths to determine required exposure times for Moon imaging. 
- Calculate the image size of the Moon at the focal plane for both telescopes. 
- Determine angular magnification using a 25 mm eyepiece for each configuration.

### Exercise 04: Maximum Likelihood Estimator
- Starting from the maximum likelihood estimation (MLE) for Gaussian-distributed data, show that maximizing the likelihood is equivalent to minimizing the sum-of-squares error.
